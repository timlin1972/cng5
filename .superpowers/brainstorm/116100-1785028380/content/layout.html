這個 panel 會嵌在現有的深色桌面式 UI 裡（跟 player/shell/notepad 一樣是客製化 panel），下面三種是可能的排版方向

A. 表格清單（Table）

像 Synology File Station：檔名、大小、時間分欄，資訊密度高，跟現有其他 panel 的文字風格最接近。

B. 縮圖網格（Grid）

像 Google 相簿：每個檔案一個方塊，圖片類可以之後加縮圖預覽，但目前 panel 寬度有限、能塞的欄數不多。

📁 raw/
🖼️ beach.jpg 3.2M ⬇
🖼️ sunset.png 5.1M ⬇

C. 精簡清單（Compact）

一行一個檔案，資訊放同一行用空白隔開，最接近現有 plugin 那種「純文字 panel」的簡樸風格，實作也最簡單。
